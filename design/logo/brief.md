# Spanreed logo exploration

## Brief

Spanreed is a minimal macOS plain-text editor for quick notes throughout the day. Its Home Note saves as the user types and reopens on launch. The first logo should identify that small, dependable writing tool in the Dock, app lists, and the repository.

Working audience: people who prefer a direct, local writing tool with few controls. Working adjectives: quiet, precise, literary, dependable. These are inferred from the product, rather than confirmed brand positioning.

The user requested all three character directions: quiet macOS utility, literary, and bold geometric. Colour is unrestricted. Show the concepts in black before selecting a palette. The existing red tile and stock S are the current reference, with no requested equity to preserve.

Success means a recognizable silhouette at 16, 32, and 64 px, portable vector artwork, readable lettering, and a shape that works in one colour and reversed. This round proposes concepts only. It does not change the installed application icon.

## Category research

The bundled logo library has 81 productivity/collaboration marks. Blue and multiple colours are common; containment, colour segments, negative space, and repeated modules recur. Studied the construction of Pagekit, Framer, Precursor, Zendesk, Speaker Deck, and Sencha to examine simple contours, letter recognition, joins, and familiarity.

Avoid a stock initial on a coloured square, a sheet of paper with a pencil, a ruled notebook, a generic fountain-pen nib, coding brackets, and gradients used as the idea. A reed reference should survive as an abstract silhouette and not require feather detail.

Word map: span / connection / bridge / continuity; reed / blade / paired stalks / writing; plain text / line / margin / rhythm; Home Note / return / persistence / open loop.

Build Scribe, Twin reeds, and Return. They offer three different silhouettes and three different mark types.

## Construction

- Scribe uses a 256-unit square, broad horizontal rails, opposing curves, and exact 45-degree terminal cuts. The S remains the first reading.
- Twin reeds uses two filled curved triangles, each with a straight 45-degree inner edge. The diagonal gap is a real opening rather than a white overlay.
- Return uses a rounded rectangular loop with a short inward rail and a wide open lower-left entrance. Radii and rail widths follow an eight-unit grid.
- The lowercase spanreed wordmark is drawn as paths for this exploration. It does not depend on a font file or carry a third-party font licence assumption.

## Review limits

The bundled library is a visual reference, not a trademark database. The selected direction needs professional trademark and reverse-image checks before public launch. Any colour, lockup system, small-size cut, or application icon is subject to a later approved logo-kit stage.
